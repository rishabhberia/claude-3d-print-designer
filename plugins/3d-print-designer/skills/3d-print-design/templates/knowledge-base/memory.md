## Every project delivers

1. CAD with checks (each with a negative control).
2. A Bambu multi-plate project, sliced for real numbers, opened in Bambu Studio.
3. An interactive 3D web page with a step-by-step assembly guide.
4. Docs in the project folder, and lessons here.
